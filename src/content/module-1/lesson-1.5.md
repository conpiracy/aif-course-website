# THE PROBLEM

Claude Skills 101.

Outcome: Students understand what Claude Skills are. They see how Skills turn one good setup (instructions + context) into something reusable.

Blocker: Even with context profiles, they still restate instructions in every chat, manually attach the right docs each time, get inconsistent behavior because setups change slightly.

# WHAT IS A SKILL

## What a Skill is

A reusable workflow that combines:
- Instructions (what the assistant should do and how)
- References (which context files it should always load)

## Why Skills matter in this system

- Set up once, reuse many times
- No more copy-pasting the same profile and instructions
- More consistent outputs across sessions and users
- Lets them build a small library of "AI workers" for specific jobs

## How to create a Skill

> Use a "Skill-Creator" skill to build new skills systematically.

# USE CASES

## Common skill use cases

- Copywriting (landing pages, emails, posts)
- Offer breakdown and research
- Product/system design helpers
- Support and documentation helpers
