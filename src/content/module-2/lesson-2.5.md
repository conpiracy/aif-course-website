# SOLUTION CONTEXT

Creating Your Solution Context File & Strategic Format Choice.

What this lesson is: Documenting your solution strategy and edges in a context file, then choosing format based on strategic leverage.

Solution Context File Structure:

# VALUE CHAIN

## Problems

- Surface problem (what they say)
- Real problem (what it is)
- Adjacent problems (what else breaks)
- Root cause (why it exists)

## Value Chain Mapping

- Current state costs
- Transformation value
- Downstream value unlocked
- Total ecosystem value

# STRATEGY

## Solution Strategy

Your method. Why it works (mechanism). What makes it defensible. Future development potential.
